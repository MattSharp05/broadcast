# Broadcast

Matthew's social media distribution system. Finished videos (from
[video-editor](https://github.com/MattSharp05/video-editor) or uploaded by hand) go into a backlog
per account; Broadcast posts them at each account's daily time slots and pulls back how each post
did. Instagram Reels first, TikTok in v1.
